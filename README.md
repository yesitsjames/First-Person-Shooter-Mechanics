# Mechanics of a First Person Shooter

This project showcases my FPS game I made in Unity.
I completed this project in six core phases.

Phase 1 was setting up the assets I had into the Unity project, creating and setting up an FPS controller, creating the starting environment, working on basic movement, and mouse looking for the player.

Phase 2 was setting up the jumping and walking functionality. Establishing to the player object what was the ground and what basic gravity was.

Phase 3 was creating the crouch mechanics, handling objects above the players head, smoothing out general movement of being able to crouch and ensuring the player doesn't sink into the ground when crouching.

Phase 4 was beginning to work on a Valorant inspired recoil spread pattern when firing the weapon. Mostly importing assets here and working on setting up my animator.

Phase 5 was setting up a system for the core of my recoil spread pattern, firing functionality, reloading animations and functionality.
<img width="1919" height="892" alt="image" src="https://github.com/user-attachments/assets/e44ea670-efbe-4abb-832d-04f97eeeb355" />


Phase 6 finally was fixing any remaining bugs that I could spot and getting friends to playtest and get their opinions! Overall, a successful playtest.


Future developments would potentially working on a full game involving delivering an explosive device to take down barriers and progress throughout a map in a 4v4 FPS moba style game.
Core elements of the explosive device and map already being worked on in the unity file. 
Initially I tried to play around with adding the agent Jett from valorant to the unity project. I made some good progress with her dash and updraft though her smokes did not work so I left her out of the project for the time being.
